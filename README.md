# Музыкант и звукорежиссёр о себе
Учебная лабораторная работа №2.

## Что реализовано
- **Семантическая верстка:** `header`, `main`, `section`, `aside`, `footer`.
- **Подключение стилей:** 
  - Внешний файл `style.css`.
  - Внутренний `<style>` (форма маркеров для списка навыков `#skills-list`).
  - Inline-стиль (`display: flex` для контейнера формы).
- **CSS-переменные** в `:root` (тёмно-синий, фиолетовый, светлый текст).
- **Позиционирование (с явными комментариями в CSS):** `static`, `relative`, `absolute`.
- **Состояния элементов:** `:hover`, `:active`, `:focus`, `:visited`.
- **Визуальные волны:** Псевдоэлементы `::before` и `::after` стилизованы под изогнутые волны и прикреплены непосредственно к названиям проектов.
- **Анимация:** `animation: shake` при наведении на волны.

## Структура файлов
- `index.html` - разметка страницы
- `style.css` - внешние стили
- `images/` - каталог для медиафайлов
  - `lb1.jpg` - изображение

## Запуск
Откройте `index.html` в браузере.

HTML и CSS проверены через W3C Validator - ошибок нет.
