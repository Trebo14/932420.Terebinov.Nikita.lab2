# Музыкант и звукорежиссёр о себе

Учебная лабораторная работа №2.

## Что есть
- Семантические теги: `header`, `main`, `section`, `aside`, `footer`
- Маркированный список навыков и нумерованный список проектов
- Изображение с `src`, `alt`, `width`, `height`
- Форма обратной связи (имя, email, сообщение)
- Сине-фиолетовая тема в стиле студии
- Внешний `style.css`
- CSS-переменные в `:root` (тёмно-синий, фиолетовый)
- Позиционирование: `static`, `relative`, `absolute`
- Состояния: `:hover`, `:active`, `:focus`, `:visited`
- Псевдоэлементы `::before` и `::after` - визуальные волны у проектов
- `animation: shake` при наведении
- Контраст текста >= 4.5:1

## Файлы
- `index.html` - страница
- `style.css` - стили
- `lb1.jpg` - аватар

## Запуск
Откройте `index.html` в браузере.

## Валидность
HTML и CSS проверены через W3C Validator - ошибок нет.
Контраст текста проверен через WebAIM Contrast Checker - не менее 4.5:1.
