# Музыкант и звукорежиссёр о себе
Учебная лабораторная работа №2.

## Что реализовано
- **Семантическая верстка:** `header`, `main`, `section`, `aside`, `footer`.
- **Подключение стилей:**
  - Внешний файл `style.css` (основной стиль).
  - Внутренний `<style>` - форма маркеров для списка навыков (`#skills-list { list-style-type: square; }`).
  - Inline-стиль - `display: flex` для контейнера формы.
- **CSS-переменные:** в `:root`: `--main-color` (тёмно-синий), `--accent-color` (фиолетовый), `--text-color` (светлый), `--font-main`.
- **Позиционирование:**
  - `static` - у `main` (значение по умолчанию).
  - `relative` - у `header` (точка отсчёта для `.rec-badge`) и у `ol li`.
  - `absolute` - у `.rec-badge` (привязан к `header`).
- **Состояния элементов:** `:hover`, `:active`, `:focus`, `:visited`.
  - `:active` на кнопке уменьшает её масштаб на 2% (`transform: scale(0.98)`).
  - `:focus` реализован и для полей формы, и для кнопки (заметная обводка + свечение).
- **Визуальные волны:** псевдоэлементы `::before` и `::after` у `.project-name` рисуют волновой контур по бокам от названия проекта. Форма волны задана через SVG-маску (`mask`), цвет - через `background-color`.
- **Анимация:** `@keyframes shake` - лёгкое дрожание волн при наведении на название проекта.

## Структура файлов
- `index.html` — разметка страницы
- `style.css` — внешние стили
