# Музыкант и звукорежиссёр о себе

Учебная лабораторная работа №2.

## Что было выполнено
- **Семантическая разметка:** `header`, `main`, `section`, `aside`, `footer`.
- **Списки:** маркированный (`ul`) для навыков и нумерованный (`ol`) для проектов.
- **Медиа и формы:** изображение с `alt`, `width`, `height`; форма с `label`, `input`, `textarea` и инлайн-стилем `display: flex`.
- **Тема и переменные:** сине-фиолетовая тема студии. CSS-переменные в `:root` для цветов и шрифтов.
- **Позиционирование (с подробными комментариями в CSS):**
  - `static` - явно указан для `main`.
  - `relative` - применён к `header` и `ol li` для создания контекста позиционирования.
  - `absolute` - применён к бейджу `.rec-badge` (в углу шапки) и псевдоэлементам-волнам (`::before`, `::after`).
- **Интерактив и состояния:** `:hover`, `:active` (уменьшение кнопки на 2%), `:focus` (обводка полей), `:visited` (цвет ссылки).
- **Псевдоэлементы:** `::before` и `::after` для создания «визуальных волн» рядом с проектами.
- **Анимация:** `@keyframes shake` (дрожание волн при наведении).
- **Доступность:** контрастность текста не менее 4.5:1.

## Файлы
- `index.html` - структура страницы.
- `style.css` - внешние стили (включая поясняющие комментарии к позиционированию).
- `lb1.jpg` - изображение.

## Запуск
Откройте `index.html` в браузере.

HTML и CSS проверены через W3C Validator - ошибок нет.
